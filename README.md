*Projects* que comparten fecha pertenecen a la misma clase, así que se

## 🧸 Cómo compilar y ejecutar

Todo está probado en Ubuntu con `gcc`/`g++` y Python 3.

```bash
# Programas en C
gcc archivo.c -o programa && ./programa

# Programas en C++
g++ archivo.cpp -o programa && ./programa

# Programas en ensamblador (sintaxis Intel, ensamblados con gcc/as)
gcc archivo.s -no-pie -o programa && ./programa

# Scripts de Python
python3 script.py
```

Los ejecutables y archivos generados no se suben al repo (están en el
`.gitignore`); cada carpeta explica cómo generarlos.
